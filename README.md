# Playable 合规检测器

纯前端 Playable（HTML5）素材合规检测工具。首版支持 **Google App Campaigns / Playable** 规则，架构为可插拔市场规则包 + 必要运行时探针。

## 使用

```bash
npm install
npm run dev
```

浏览器打开本地地址后，上传 `.zip` 或 `.html`，左侧查看检测结果，右侧预览素材。

```bash
npm test
npm run build
```
