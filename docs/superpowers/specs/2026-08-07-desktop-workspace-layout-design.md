# 桌面应用工作区布局 — 设计文档

**日期：** 2026-08-07  
**状态：** 待用户审阅  
**范围：** Electron / 浏览器共用 UI 骨架；从瀑布流改为经典左右分栏；不改动规则引擎与检测逻辑。

---

## 1. 背景与目标

瀑布流布局是网页竖向阅读的折中方案。产品已升级为 Electron 桌面应用，应回到设计文档原方案：**左结果 / 右预览**，并容纳后来新增的控制台、设备档位与 WebContentsView 预览。

**成功标准：**

1. 默认窗口下，检测结论与预览同屏可见，无需纵向滚过整页才看到报告。
2. 右栏用 Tab 切换「预览 | 控制台」；切到控制台时 Electron 预览视图不遮挡日志。
3. 纯 `npm run dev` 使用同一套布局（无设备档位杠杆）。
4. 静态/运行时检测行为与现网一致，仅改排版与显隐。

**非目标：**

- 可拖拽调栏宽、独立控制台窗口
- 新市场规则或 Finding 数据模型变更
- 视觉品牌大改版（沿用现有暗色工具风）

---

## 2. 布局方案（已选：方案 1 + 控制台方案 C）

### 2.1 结构

```
┌─ 顶栏（固定）──────────────────────────────────────────┐
│  PV 品牌 · 副标题（Electron·档位 / 浏览器） │ 市场选择 │
├─ 左栏 ~42% ──────────────────┬─ 右栏 ~58% ────────────┤
│ ① 紧凑上传区                  │ Tab：[预览] [控制台]   │
│ ② 状态 + 错误/警告/信息计数   │ ─── Tab 内容区 ───     │
│ ③ Finding 分组列表（可滚动）  │ 预览或控制台           │
└──────────────────────────────┴────────────────────────┘
```

### 2.2 分区职责

| 区域 | 职责 |
|------|------|
| 顶栏 | 品牌、会话形态说明、市场选择 |
| 左栏 | 上传、检测状态、报告阅读与证据 |
| 右栏 · 预览 | 分辨率/档位/刷新/采集、机型框、FPS |
| 右栏 · 控制台 | console 镜像、OOM 预警、清空 |

### 2.3 响应式

- **≥900px：** CSS Grid 左右分栏（约 `1fr 1.35fr`，近 42%/58%）。
- **&lt;900px：** 上下堆叠（上：右栏 Tab；下：左栏结果），避免双栏过挤。
- 主进程默认窗口可调整为约 **1200×800**（可选增强，非阻断）。

---

## 3. 左栏细节

### 3.1 上传

- 紧凑拖拽/点击区；不再占满首屏高度。
- 展示文件名；有 bundle 摘要时显示体积、文件数。
- 一行 `status`（解析中 / 静态完成等）。

### 3.2 报告

- 摘要条：错误 / 警告 / 信息计数（沿用现有 severity 色）。
- Finding 按政策 / 大小 / 工具 / 结构分组折叠。
- 点击 Finding 在左栏展开证据；不强制跳转预览内锚点。
- 列表区域 `overflow: auto`，顶栏与右栏固定不随之整体滚动。
- 空态：「上传素材后在此显示检测结果」。
- 若现有「复制文本摘要」能力存在则保留；本迭代不强制新增。

### 3.3 不放在左栏

控制台、FPS、设备档位控件 —— 一律归右栏。

---

## 4. 右栏细节（预览 | 控制台）

### 4.1 Tab

- 默认：**预览**。
- 切换不重新跑静态检测。
- **未读提示（建议做）：** 控制台有新日志且当前不在控制台 Tab 时，Tab 上显示小红点；进入控制台后清除。

### 4.2 预览 Tab

- 工具条：分辨率、设备档位（仅 `window.pvDesktop`）、刷新、重新采集；（浏览器）新窗口打开。
- 档位说明文案保留（切换将重启 + 真机边界）。
- 机型框 + FPS 角标行为与现实现一致。
- **Electron：** 机型框 bounds → `updatePreviewBounds`。
  - 离开预览 Tab → `hidePreview()`
  - 回到预览 Tab → `showPreview`（或等价 show）+ 同步 bounds
  - 避免 WebContentsView 盖住控制台 Dom

### 4.3 控制台 Tab

- 复用 `ConsolePanel`：全高列表 + 清空。
- 继续接收 console / OOM / 探针相关文案。

### 4.4 空态

- 未上传：预览占位文案；控制台可为空列表。

---

## 5. 视觉原则

- 沿用现有 CSS 变量与暗色工具风；去掉瀑布流 `max-width: 960px` 居中约束。
- 工作区铺满窗口；左右细分割线；右栏略深以突出「舞台」。
- 不新增大仪表盘、统计卡片墙、营销块。

## 6. 实现范围

### 6.1 改动面（预期）

| 位置 | 变更 |
|------|------|
| `src/App.tsx` | waterfall → workspace；右栏 Tab 状态；Electron 显隐 |
| `src/styles.css` | `.workspace` / `.pane-left` / `.pane-right` / Tab 样式；压缩上传 |
| `src/ui/PreviewPane.tsx` | 可拆出工具条；配合父级 Tab（预览内容仍在此） |
| `src/ui/ConsolePanel.tsx` | 嵌入右栏 Tab；可选未读由 App 驱动 |
| `src/ui/UploadZone.tsx` | 紧凑样式（class 或 prop） |
| `src/ui/ReportPanel.tsx` | 适应左栏滚动容器（尽量少改 API） |
| `electron/main.cjs` | 可选：默认窗口 1200×800 |
| `README.md` | 说明桌面为左右分栏 |

### 6.2 不变

- `src/engine`、`src/markets`、`src/vfs`、`src/parser` 规则与解析逻辑
- IPC / `pv-preview` / CDP / 档位 relaunch 语义（仅多 Tab 显隐）

### 6.3 验收

1. `electron:dev`：左报告 + 右预览同屏；切控制台日志可见且预览层不挡。
2. 切回预览：画面与 bounds 恢复正常。
3. `npm run dev`：同布局，无档位下拉。
4. 上传 → 检测 → Finding / 控制台 / FPS 行为与改版前一致。
5. &lt;900px 宽度下可上下堆叠使用，无严重重叠。

---

## 7. 风险与缓解

| 风险 | 缓解 |
|------|------|
| Tab 切换后 WebContentsView 错位 | 进入预览 Tab 强制 `updatePreviewBounds`；离开即 hide |
| 左栏 Finding 过长难扫 | 分组折叠 + 独立滚动 + 摘要计数置顶 |
| 窄窗双栏挤压 | 900px 断点改为上下堆叠 |
